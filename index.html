Sources and privacy

Map tiles: OpenFreeMap. Place search and context: OpenStreetMap contributors via public Nominatim / Overpass endpoints. Buildings, trees and tags are only as complete as public OSM data. Calculated footprint area is approximate; indoor floor area is not the same thing. The HTML has no app backend or account system.
